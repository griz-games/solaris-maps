# Introduction

This repo contains custom maps I've built for Solaris, based on python helper functions and the underlying work done by [@IHateAttackMaps](https://github.com/IHateAttackMaps) for the [Custom Galaxy Editor](https://github.com/IHateAttackMaps/solaris-custom-galaxy-editor). Everything was vibe coded by Claude Code and reviewed by me. I take no credit for the underlying scripts.

# Usage

Simply copy JSON files to use the existing maps. Model wide parameters can be changed using the python build scripts to make universe-wide changes (such as changing the resource scaling function for the 36p spy v. spy map). Details on parameters are found in the underlying scripts.

Details on the map and the game design choices can be found on the Github page that accompanies this repo.
